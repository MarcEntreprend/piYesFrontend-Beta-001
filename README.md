## Run Locally

**Prerequisites:** Node.js

```bash
# Install dependencies
npm install

# Run the app
npm run dev
```

**Or** run it so it can be accessed on other devices on the same network  
(then open `http://[IP_ADDRESS]:...`):

```bash
npm install
npm run build
npm run serve
```
